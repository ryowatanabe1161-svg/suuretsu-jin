# 数列陣 〜ふーさんと数字タイルの陣〜

▶ **遊ぶ:** https://ryowatanabe1161-svg.github.io/suuretsu-jin/

数字タイルで「同じ数字の組」や「同じ色の連番」を作って場に並べ、手札を先に出し切ったら勝ちのタイル並べゲームです。スマホのブラウザで、2〜4人でオンライン対戦できます。空いた席には CPU の **ふーさん🐻**（弱い／普通／強い）が入ります。

## ルール
- タイルは 106 枚あります。1〜13 の数字が 4 色（墨● / 紅◆ / 藍▲ / 山吹★）で 2 枚ずつ、それにジョーカー 🐻 が 2 枚です。最初に 1 人 14 枚ずつ配ります。
- 組は次の 2 種類です。どちらも 3 枚以上で作ります。
  - **グループ**：同じ数字で色がすべて違う 3〜4 枚
  - **ラン**：同じ色の連続した数字 3 枚以上（13 の次は 1 には戻りません）
- **初回**は、手札だけで作った組の合計を 30 点以上にして出します。初回を出すまでは、場のタイルに触れません。
- 初回を出した後は、場の組を自由に組み替えたり分けたりできます。ただし手番の終わりには、場の組がすべて正しい形になっていて、手札から 1 枚以上出している必要があります。
- 出せないとき、または出したくないときは 1 枚引いて手番を終えます。
- 誰かが手札を出し切ったら終了です。負けた人は「自分の残り点」がマイナスになり、勝った人はその合計を得ます（ジョーカーは 30 点）。山が尽きて全員が続けてパスした場合は、残り点がいちばん少ない人の勝ちです。

## 操作
- 手札または場のタイルをタップして選びます（複数可）。そのあと組の「＋」か「＋ 新しい組」をタップして置きます。
- 「リセット」で手番の最初の状態に戻し、「手札へ」でその手番に出したタイルを手札に戻します。「決定」で確定し、「1枚引く」で引いて手番を終えます。
- 形が正しくない組は赤枠で表示し、そのあいだは決定できません。初回のあいだは、状況欄に x/30 点を表示します。
- 手札は「色順」と「数字順」で並べ替えられます。

## オンライン機能
- PeerJS（WebRTC）を使ったホスト型です。部屋コード、QR、招待リンクで参加でき、サーバー側の状態は持ちません。
- 自分の手札だけが届きます（他人の手札は終了時に公開されます）。
- 再読み込みや再接続をしても席に戻れます。ホストは途中で中断・もう一度ができます。
- ゲーム中は表示しませんが、ポータルから開いたときは「🏠 ひろばへ」でポータルに戻れます。

## ふーさん（CPU）
| レベル | 動き |
|---|---|
| 弱い | 手札だけで組を作って出します（ジョーカーは使いません）。わざと引くこともあります。 |
| 普通 | 手札の組に加えて、場への付け足し、ランへの割り込み、長い組の端を借りる、を行います。 |
| 強い | いくつかの組み立て方を試します。さらに場の組を崩して作り直す探索をして、残り枚数と残り点がいちばん少ない手を選びます。 |

自動対戦（2 人）の結果は、普通が弱いに 60/60 勝、強いが普通に約 63% 勝（94/150）でした。

## ファイル
- `index.html`：画面と CSS
- `app.js`：UI とネットワーク
- `logic.js`：ルールと CPU（Node からも使えます）
- `config.js`：設定
- `vendor/`：PeerJS と QR
- `test/logic.test.js`：ルールのテスト
- `test/e2e.js`：ブラウザでのオンライン E2E
- `test/stun-server.js`：テスト用の STUN

## テスト（開発用・test/ はこのリポジトリには含みません）

```
node test/logic.test.js
node test/stun-server.js 172.30.0.2 3478 &
python3 -m http.server 8795 --bind 0.0.0.0 &
node test/e2e.js
```

名前とアートはオリジナルです。
